# CV-Generator (The Odin Project)

An interactive, modern resume builder built with **React** as part of [The Odin Project](https://www.theodinproject.com/) Frontend curriculum.

This Application allows users to input, edit, and preview their personal details, education, and practical work experience in real time, with an easy option to export their finalized CV as PDF.

## Features
- **Realtime Preview:** Instantly see updates on your CV as you type into the input fields.
- **PDF Export:** Clean print layout configured via CSS media queries to hide forms when exporting.
- **Responsive Design:** Optimized for seamless viewing on desktop, tablets, and mobile screens.

## Tech Stack
- **Framework:** [React](https://react.dev/)
- **Build Tool:** [Vite](https://vite.dev/)
- **Styling:** CSS3 / Modern CSS (Flexbox & Grid)
